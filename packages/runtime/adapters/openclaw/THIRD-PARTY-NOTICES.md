# OpenClaw native runtime

This adapter executes the unchanged published `openclaw@2026.9.8` Node CLI, from [openclaw/openclaw](https://github.com/openclaw/openclaw/releases/tag/v2026.9.8), release commit `fc23bc864e4553c2d215e479eeec47b67a0bf943`. OpenClaw supplies its embedded Agent loop, tools, and native session database. It is distributed under MIT; the complete upstream license is retained in `LICENSE.openclaw`. Dependencies remain subject to their respective notices in the installed npm distribution.

The t-alent adapter is MIT licensed. Its recipe contains only JSON and prompts; no upstream executable is included in the recipe archive. `agent-sources/openclaw/0.2.0.json` records npm integrity, source version, and adapter version separately.
